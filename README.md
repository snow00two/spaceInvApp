# p5.js Pyramid simulator 

By snow00two


This program is a demonstration of 3D animation using p5.js WEBGL mode.
p5.js is a JavaScript API transplanted from Processing that is a API developed in Java. It consists of four parts:

- Warp out of space ships.
- Emergence of space cubes.
- Counter attack of Earth fighters.
- Landing of space cubes before the Great Pyramids, observed from a Helicopter.
